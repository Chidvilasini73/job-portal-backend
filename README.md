# Job Portal Application – Backend

## Project Overview
This repository contains the backend of a Job Portal Application developed using Java and Spring Boot. It provides REST APIs to manage job listings and job applications and connects the frontend with the database.

## Technologies Used
- Java
- Spring Boot
- SQL
- REST APIs
- Maven

## Features
- Create and manage job listings
- Retrieve available jobs
- Update job details
- Delete job listings
- Support job application functionality
- Backend API integration with the frontend

## Backend Functionality
- Handles HTTP requests through REST APIs.
- Performs CRUD operations on job data.
- Connects with the database.
- Supports communication with the React.js frontend.

## Project Structure
- `src/` – Backend source code
- `pom.xml` – Maven dependencies and configuration
- `Dockerfile` – Docker configuration
- `mvnw` – Maven wrapper

## How to Run the Project
1. Clone this repository.
2. Open the project in IntelliJ IDEA or Eclipse.
3. Configure your database settings in `application.properties`.
4. Run the Spring Boot application.
5. Test the APIs using Postman.
